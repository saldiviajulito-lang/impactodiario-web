# Fotos de funcionarios

Guardá acá las fotos de cada funcionario en formato `.jpg` o `.png`, cuadradas
(o lo más cuadradas posible, porque se recortan en círculo). Cada archivo debe
llamarse exactamente como en la columna "Archivo esperado" — el nombre sale
automáticamente a partir del nombre en `src/data/sampleData.ts`
(ver función `slugify`).

Si un archivo no existe todavía, el sitio muestra el placeholder gris
automáticamente. No hace falta tocar código: apenas subís el archivo con el
nombre correcto, la foto aparece sola.
