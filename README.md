# impactodiario-web

sitio web impactodiario.com.ar

Este es un proyecto [Next.js](https://nextjs.org) creado con [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

Primero, corré el servidor de desarrollo:

```bash
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

Podés empezar a editar la página modificando `src/app/page.tsx`. La página se actualiza automáticamente mientras editás el archivo.
